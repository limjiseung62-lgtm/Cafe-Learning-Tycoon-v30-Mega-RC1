게임 · 학생 안내 · 공간 성장 비교

포함 범위

GROWTH Lv.1~30, 선택형 유료 증축, 48→320→1,200→3,072칸 실제 공간, 가구 19종 구매·보관·회전·통로 검사, 기존 직원 교착 수정 및 주문·서빙, CLASS 15·30분 랜덤 사건을 유지합니다. 신규 공간은 자동으로 가구가 채워지지 않습니다.

카페 방식의 과목·학년·학기·단원·학습 요소 선택 UI를 사용합니다. 수학 3~6학년 48단원 49,233개 고유 문항 객체, 과학 생물과 환경 승인 104문항(0.1.3)을 연결합니다. 국어는 이번 신규 선택에서 제외합니다. 내부 후보 명칭이 남은 문항도 최신 운영 승인 receipt·고정 해시 공급 범위 안에서만 사용합니다. 공급 승인과 게임 실제 QA는 별개입니다.

학습·생산

기본형→즉시 쌍둥이 흐름당 정상 생산은 최대 1회입니다. 새로운 기본 출제 기회는 같은 문항이어도 다시 보상합니다. 독립 오답노트는 무보상이며 서로 다른 동등 문제 2연속 정답으로 완료합니다. 최초 성적은 바꾸지 않고 공통 PNG 생성기를 재사용합니다. 동등 후보가 부족하면 보류하고 다른 개념으로 대체하지 않습니다.

실제 시간 검증

과학 CLASS 실제 30분 종료 및 새로고침·이어하기, Lv.30 수학 혼합 2단원 GROWTH 실제 15분 종료를 확인했습니다. 고레벨 카페는 합성 QA 저장을 가져온 조건이며 실제 학생 성장 실측이 아닙니다. GROWTH 10응답·판매 89,917원·30팀 서빙 조건에서 첫 정답률 75%가 복습 후에도 유지됐고 최종 해결률은 87.5%→100%로 바뀌었습니다. 독립 복습 전후 음식 생산 원장 7회는 같았습니다.

성능과 경제의 한계

이전 메가 렌더러의 PC 30분 실험은 Lv.10/20/30 평균 약 60/59.4/59.3FPS였지만 순간 최대 프레임 지연 약 63/429/879ms가 남아 있습니다. 같은 렌더러의 단일 Lv.30 일반 영업 15분에서는 평균 59.5FPS였으며, 공통 문제은행 대용량 초기 파싱 조건과 직접 같은 측정은 아닙니다. 수학 전체 데이터는 전송 약 14MB, 압축 해제 JSON 약 141MB입니다. 학교 기기의 메모리·초기 로딩은 검증 전입니다.

완성 배치에서 증축 투자 총액 대비 추가 수익 회수는 10→20 중간값 약 84회, 20→30 약 97회로 긴 편입니다. 돈을 모아 구매하는 시점(약 3/8회)과 투자 회수는 다릅니다. +8%/+18% 준비 구역 매출 보정은 Lv.20/30 로컬 메가 전용이며 학습 정답 보상·CLASS 경제를 바꾸지 않습니다. Lv.30은 넓은 빈 공간이 남을 수 있고 풍부한 밀도·학생 재미는 추가 시각 검수가 필요합니다.

아직 검증되지 않은 것

  • 실제 학교 태블릿·학교망·학생 플레이 재미 및 접근성 전체 검수
  • 모든 콘텐츠의 새 교사 개별 재검수(기존 공급 승인 재사용)
  • 공개 URL에서의 장시간 실제 수업 결과(로컬 실제 15/30분과 구분)

공식 v2.0.0과 이전 학생 테스트판은 변경하지 않습니다. 테스트 저장은 별도 키이며 로그인·서버 저장·유료 인프라를 추가하지 않습니다.

이어하기·직원 복구 업데이트

초반 GROWTH에서 손님 정보가 저장되지 않아 진행 중인 직원 주문을 복원하지 못하던 경로를 수정했습니다. 이전 형식은 원본을 별도로 보관한 뒤 복구합니다. 원본에 손님 정보가 없는 경우 진행 중이던 주문 자체는 재구성할 수 없어 취소하지만 저장된 돈·재고·학습 기록을 임의로 늘리거나 차감하지 않습니다.

영업 화면의 큰 직원 위치 복구 버튼으로 겹친 직원을 안전한 위치에 다시 배치할 수 있습니다. 유효한 주문과 운반 음식은 유지하고, 같은 주문의 결제를 반복하지 않습니다.

매장 관리 · 증축·가구 배치에서 영업 중 유료 증축, 가구 구매, 배치·회전·보관이 가능합니다. 손님이 쓰는 좌석과 직원 통로를 막는 변경은 거절합니다. 관리 중에도 원래 영업 종료 시각은 유지됩니다. Lv.3 이후 기존 미션을 유지하고 도움 손님은 최대 3회 방문 기회를 제공합니다.

카페가 열리지 않으면 사이트 데이터를 지우지 마세요. 같은 주소를 새로고침한 뒤 이어하기를 시도하고, 남은 오류 문구를 교사에게 알려 주세요. 이미 삭제된 브라우저 기록은 서버에 보관되지 않으므로 별도 JSON 백업 없이 되살릴 수 없습니다.

첫 사업 파트너 · 매니저 업데이트

GROWTH에서 첫 유료 증축의 결제와 공사가 끝나면 유나·하준·소이 중 한 명을 선택해요. 레벨만 올렸을 때는 등장하지 않아요. 나중에 골라도 선택 기회가 저장됩니다. 이미 확장한 기존 카페는 돈·가구·직원을 바꾸지 않고 영입 기회만 받습니다.

선택한 매니저는 카페 안에서 실제로 걷고 대화합니다. 직원 정원이나 서빙 작업에 들어가지 않아요. 캐릭터를 누르거나 큰 매니저 버튼을 눌러 현재 재고·직원·좌석·증축 목표 조언을 볼 수 있습니다. 모든 매니저가 핵심 조언을 제공하며, 결정과 구매는 학생이 직접 합니다.

본부 설립·도시 경영은 이번 업데이트에 구현되지 않았습니다. 매니저가 후속 꿈으로만 안내합니다. 실제 학교 기기 성능·학생 재미 검수는 대기입니다.
