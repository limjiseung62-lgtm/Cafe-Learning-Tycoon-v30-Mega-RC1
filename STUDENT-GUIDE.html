나만의 메가 카페를 키워요

게임으로 돌아가기 · 교사용 관찰표

  1. 수업 게임(CLASS)은 15분 또는 30분짜리 새 카페예요. 나가 있는 시간도 영업시간에 포함돼요. 30분은 중간 저장·이어하기를 지원해요.
  2. 내 카페 키우기(GROWTH)는 15분씩 이어 키워요. Lv.30까지 성장할 수 있고, 실제 공간 증축은 직접 게임 머니로 구입해요.
  3. 과목·학년·학기·단원을 고르세요. 수학은 3~6학년 48단원, 과학은 4학년 2학기 생물과 환경이에요. 국어는 이번 테스트에서 제공하지 않아요.
  4. 기본 문제 또는 바로 이어지는 쌍둥이 중 하나를 맞히면 해금 메뉴마다 음식 +1! 같은 학습 흐름의 중복 클릭은 추가 생산되지 않아요. 두 문제 모두 틀리면 오답노트에 원래 문제 하나만 남아요.
  5. 지난 학습·오답노트에서 서로 다른 두 문제를 연속으로 맞히면 복습 완료예요. 이 독립 복습은 음식 보상이 없고 최초 성적도 바꾸지 않아요.
  6. 종료 후 학습 결과 PNG·복습 후 PNG·복습지·정답 해설을 저장할 수 있어요. PNG는 여러 페이지일 수 있으니 모두 저장하세요.

저장과 복구

이 테스트판은 공식판·이전 테스트판과 저장 키가 달라요. 다른 주소나 기기로 자동 이전되지 않아요. 카페의 기록과 백업에서 JSON을 저장하고, 지난 학습 메뉴에서도 전체 학습 JSON을 백업해 주세요. 새 백업은 카페와 지난 학습 기록을 함께 포함해요.

이전 버전 원본 저장은 지우지 마세요. 가져올 수 없는 백업을 임의로 고치지 말고 그대로 보관하세요. 같은 학습 기록이 이미 더 진행된 경우 덮어쓰지 않고 복원을 멈춰요. 저장 오류가 나면 초기화하지 말고 JSON을 보관한 뒤 다시 접속하세요. 여러 창에서 같은 카페를 동시에 운영하지 마세요.

이름·학교·연락처를 입력할 필요가 없어요. 로그인이 없으며 기록은 사용하는 브라우저에 저장돼요. 브라우저 데이터 삭제·시크릿 모드 종료 전에 백업하세요.

테스트판 안내

무료 공개 테스트 후보이며 공식 v2.0.0을 대체하지 않아요. 실제 학교 태블릿·학교망 및 학생 재미 검수는 아직 진행 전이에요. 수학 전체 자료는 처음 선택할 때 약 14MB를 받으므로 연결이 느리면 잠시 기다려 주세요.
